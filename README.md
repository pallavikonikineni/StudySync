# StudySync 🚀

StudySync is a Full Stack Student Productivity and Learning Management Platform built using React, Spring Boot, and MySQL.

## Features

* Student Registration & Login
* Dark/Light Mode
* Study Task Management
* AI Study Suggestions
* Productivity Dashboard
* Study Analytics
* Leaderboard System
* CSV Export
* Notifications
* Responsive UI
* Full CRUD Operations

## Tech Stack

### Frontend

* React.js
* CSS
* Axios
* Recharts

### Backend

* Spring Boot
* Java
* REST APIs

### Database

* MySQL
